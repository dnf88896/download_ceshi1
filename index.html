这个页面用于分发 voices38-pragmata.iso。因为 ISO 体积约 33.85 GiB，文件被拆成多个 GitHub Release 附件。请下载全部分卷后在本地合并。

Windows 合并方法

  1. 从下载页保存所有 voices38-pragmata.iso.part001、part002 等分卷到同一个文件夹。
  2. 在该文件夹空白处按住 Shift 右键，选择“在终端中打开”。
  3. 运行下面的命令：
copy /b voices38-pragmata.iso.part* voices38-pragmata.iso

macOS / Linux 合并方法

cat voices38-pragmata.iso.part* > voices38-pragmata.iso

校验

合并后可以用 SHA256 校验文件完整性。Windows PowerShell：

Get-FileHash .\voices38-pragmata.iso -Algorithm SHA256

将输出结果与下载页里的 SHA256SUMS.txt 对照。
